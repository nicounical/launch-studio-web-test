# Launch Studio — web nueva (prueba)

Repositorio de prueba de la nueva web de [Launch Studio](https://www.launchstudiogroup.com). No es el definitivo.

Web estática: HTML, CSS y JavaScript, sin dependencias ni compilación.

## Estructura
- `index.html` — inicio, con la portada animada
- `proyectos.html` y `proyectos/` — listado y una página por proyecto
- `contacto.html`
- `css/estilos.css` — estilos de todo el sitio
- `js/portada.js` — animación de la portada · `js/sitio.js` — cabecera y formulario
- `assets/img/` — imágenes (mientras estén vacías, se cargan desde la web actual)

## Verla en local
Abre `index.html` en el navegador.

## Pendiente
- Formulario de contacto sin servicio de envío (abre el correo del visitante).
- Las páginas llevan `noindex` mientras sea una prueba.
